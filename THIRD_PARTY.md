# Dependencies and provenance

No runtime dependencies. Python and its standard library are external PSF-licensed
prerequisites. Development tools are pytest (MIT), Ruff (MIT), coverage.py
(Apache-2.0), build (MIT), setuptools (MIT) and separately installed transitive
dependencies. No third-party implementation or datasets are copied or vendored.
Examples and fixtures are original synthetic data. Shared packaging and CI
scaffolding is reused from earlier repositories of this same owner.

Official GitHub Actions are pinned to verified commit SHAs. Workflows only test,
check history and build; they have no repository write permission or update bots.
Public standards and issue reports are linked in the README as reference material.
